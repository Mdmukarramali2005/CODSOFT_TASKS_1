## Task 1: Data Cleaning & Preprocessing

### Objective

The objective of this project is to clean and preprocess a raw car dataset using Python and Pandas to make it suitable for further analysis.

### Dataset

Automobile Industry Dataset

### Tools & Technologies

* Python
* Pandas
* NumPy
* VS Code / Jupyter Notebook

### Steps Performed

* Imported the dataset using Pandas.
* Inspected the dataset using `head()`, `shape()`, and `info()`.
* Identified missing values using `isnull().sum()`.
* Filled missing values in numerical columns using the median.
* Filled missing values in categorical columns using the mode.
* Checked for duplicate records and removed them if present.
* Verified the data types of all columns.
* Saved the cleaned dataset as `cleaned_car_dataset.csv`.

### Outcome

The dataset was successfully cleaned and prepared for Exploratory Data Analysis (EDA) and visualization.
