# CODSOFT Data Analytics Internship

## Task 3 - Data Visualization Dashboard

### Objective

The objective of this task is to create meaningful visualizations from a cleaned car dataset and identify useful insights using Python.

### Dataset

* **Dataset:** Cleaned Car Dataset
* **Format:** CSV

### Tools & Libraries Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

### Visualizations Created

* Bar Chart – Top 10 Car Brands
* Histogram – Selling Price Distribution
* Scatter Plot – Mileage vs Selling Price
* Pie Chart – Fuel Type Distribution
* Line Chart – Average Selling Price by Manufacturing Year
* Correlation Heatmap

### Key Insights

* The dataset contains cars from multiple manufacturers.
* Most vehicles fall within a common selling price range.
* Mileage influences the selling price of vehicles.
* Petrol and Diesel vehicles make up the majority of listings.
* Newer vehicles generally have higher average selling prices.
* Correlation analysis highlights relationships among numerical features.

### Project Files

* `Task3_Data_Visualization.ipynb`
* `cleaned_car_dataset.csv`
* `task3_dashboard.png`

### Outcome

This project demonstrates how data visualization techniques can be used to analyze car market data and communicate insights effectively.
